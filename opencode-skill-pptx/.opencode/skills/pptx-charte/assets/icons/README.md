# assets/icons/

Icônes **complémentaires** (en plus de celles contenues dans le template).

- Formats : PNG (recommandé, fond transparent, ≥ 256 px), JPG, GIF, BMP, TIFF. **Pas de SVG** : exporter en PNG.
- Le nom du fichier devient le nom d'icône : `cloud-securise.png` → `"icon": "cloud-securise"`.
- Utiliser les couleurs de la charte. Un seul style d'icône (trait / aplat) pour tout le jeu.
- `scripts\run.cmd icons` liste toutes les icônes disponibles (template + ce dossier).

Icônes du template : une diapositive du template (titre ou texte contenant « icône », « icon » ou « picto ») regroupe les icônes ; chaque icône est une image ou un groupe de formes nommé(e) (nom de la forme, texte alternatif, ou légende placée juste dessous). Si les icônes sont sur d'autres diapos : régler `icon_library_slides` dans `config/charte.json`.
